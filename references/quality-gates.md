# 质量门禁

## 阶段门禁

| 阶段 | 必须通过 | 失败时的处理 |
| --- | --- | --- |
| 启动 | 研究边界、标的、交付路径、可证伪初始假设完整 | 仅追问会改变结果的缺口 |
| 行业分析 | 来源台账字段完整；关键数字有地区、期间、单位与等级；行业交接包包含结论、证据、反证、边界和未决问题 | 返回行业阶段补齐，不提前写公司结论或最终正文 |
| 公司分析 | 公司结论引用行业交接包；主体、业务、经营、行业关联、反向证据与未决问题完整；行业任务已标记不适用 | 返回公司分析阶段，不重复完整行业研究 |
| 竞争分析 | 购买旅程与竞品簇完整或满足停止规则；纳入、排除和可比依据完整 | 返回竞争分析阶段，不提前形成公司投资结论 |
| 综合判断 | 决策问题已回答；行业、公司与竞争判断完成交叉验证；证据冲突、失效条件和章节蓝图完整；每章具有页面、模块与证据归属 | 返回综合阶段处理，不进入读者版写作 |
| 叙事 | 中心论点、章节顺序和连续正文完整；页面与模块归属保持不变；分析脚手架不可见；表格均有必要性说明 | 返回叙事编辑阶段重写 |
| 模块完成审计 | 当前输出路径的模块集合、规定要素、证据、必要表格和上游阶段产物全部对齐 | 返回相应研究阶段补齐，整体状态保持未完成 |
| 交付 | 聊天回复的链接和判断边界完整，或 Excel 的版式、页面结构和来源台账完整 | 修复内容、版式或链接后再交付 |
| 复盘 | 研究记录通过脚本；经验经用户确认 | 未确认经验只保留在项目记录 |

## 交付验收清单

- 核心判断回答了“为何成立、何时失效、还缺什么”。
- 成品形成连贯咨询叙事；章节标题表达判断，段落之间存在承接关系，分析标签和内部字段未进入读者版正文。
- Excel 正文页从上到下连续阅读，主要观点未被项目符号、标签卡片或宽表替代；数据表只用于必要的横向比较。
- 任务卡明确记录研究对象、全球上市状态、交易所与证券代码、资本市场阶段、`industry_orientation`、`analysis_dimensions`、判断理由、公司成熟度、信息完整度和固定 `output_profile`。行业任务在第二级结束，公司任务进入第三级；消费方向未被强行展开为完整技术栈，科技方向的工程瓶颈未被压缩为关键词，融合方向同时完成消费、科技及二者商业连接分析。
- 行业分析先完成，公司分析与竞争分析随后并行，二者都通过门禁后再进入综合判断、叙事和交付；每个阶段已形成压缩交接包，后续阶段未重新加载无关原始材料。
- `narrative-draft.json` 的标题、页面归属、模块归属和证据编号与 `analysis-synthesis.json` 的章节蓝图一致；叙事与交付阶段没有引入新结论或新证据。
- 公司研究以有标题的投资要点开场，未输出伪精确综合打分。
- 竞品比较包含类别与可比原因，覆盖了相关的非制造商角色。
- 每项市场数字说明地区、期间、单位和事实或预测属性。
- 一级项目仅保留现实可得的核验动作。
- 所有关键来源提供完整直达链接。
- 关键来源按 A、B、C、D 分级，来源等级与结论用途匹配。
- 竞品地图包含纳入项目、排除项目、检索簇和停止原因。
- 聊天回复已检查核心判断、直达链接、判断边界和待核验项；Excel 已逐表渲染核验。
- 技术栈表已通过列宽、行高或拆表保证完整论述可扫描；工程瓶颈每层至少包含问题、成因和商业影响。
- 语义内容已运行 `scripts/validate_content_contract.py`；来源统计与证据台账逐条一致；阶段产物路径真实存在且内容结构可读。
- Excel 路径的所有阶段产物使用 Schema v3；正文、投资要点、竞品、图表和研究结论的证据编号均能回连同一个证据台账。
- `delivery-check.json` 字段、工作表清单、渲染清单、可视化来源和最终文件路径已由跨产物对账器核验。
- `completion-audit.json` 与当前输出路径合同完全一致；所有模块均有可阅读分析、可回连证据和唯一可见的 Excel 位置，合同要求明细表的模块已经写入结构化表格。叙事已覆盖的模块不重复复制审计正文。

## 缺陷分级

| 等级 | 含义 | 处理 |
| --- | --- | --- |
| 阻断 | 标的错误、关键结论无来源、交付文件无法打开 | 不交付 |
| 重大 | 口径混用、错误资本市场身份、一级项目使用不现实指标 | 修复后交付 |
| 一般 | 个别链接缺失、表格截断、未标注待核验 | 修复或显著标注 |
| 轻微 | 不影响判断的措辞或版式瑕疵 | 集中修订 |

## 阻断条件

出现以下任一情况时不得交付：主体识别错误；关键结论无来源；市场边界混用；一级项目使用上市公司式经营指标；分析脚手架在成品中大面积可见；关键链接不可读；综合判断阶段缺失；叙事稿引入综合判断之外的新证据。Excel 路径另将阶段产物缺失、核心模块或规定要素缺失、必要明细表缺失、模块未写入成品、Schema 字段漂移、未知证据编号、来源统计不一致、交付文件无法打开和关键工作表不可读视为阻断缺陷。
