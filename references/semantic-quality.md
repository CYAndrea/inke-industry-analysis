# 语义质量验收

## 技术论述

当 `industry_orientation=technology` 或 `hybrid` 时，每个关键技术层级至少提供两句完整句子，并覆盖：

1. 问题或瓶颈发生在哪个部件、工艺、数据环节或部署阶段。
2. 形成瓶颈的原因和性能、成本、交付或合规影响。
3. 当前行业解决方案、量产状态或仍未解决的缺口。
4. 对产品竞争力、商业化和投资判断的影响。

仅包含“低温、寿命、成本、热管理”等逗号分隔名词的文本不通过。句子数量和必需元素由 `scripts/validate_content_contract.py` 检查。

## 投资要点

每条投资要点至少包含依据、成立条件、失效条件和待验证信息。没有来源的“领先”“显著”“较强”等判断标记为待验证，不能直接作为结论。

## 证据台账

每条关键证据记录结论类型、来源角色、权威等级、独立性、发布日期、地区、期间、单位、口径、使用方式、限制条件和直达链接。来源统计必须与台账逐条一致。

## 跨段落叙事

单段文本合格后，再检查整份叙事稿。每个章节至少包含两个连续段落，章节标题表达完整判断；每个段落应当增加机制、证据解读、反向证据、决策含义或判断边界中的至少一项。正文自然完成结论、机制、证据、投资含义和判断边界，不显示内部字段名称。章节的 `reader_page_id`、`covered_module_ids` 和 `evidence_ids` 必须与综合判断蓝图一致。运行 `scripts/validate_narrative_contract.py`，未通过时不得进入交付制作。
