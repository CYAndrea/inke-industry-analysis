# 输出配置与三级路由

## 路由字段

| 字段 | 可选值 | 用途 |
| --- | --- | --- |
| `research_subject` | `industry`、`company` | 判断第二级结束，还是继续进入公司研究 |
| `capital_market_stage` | `primary_market`、`secondary_market`、`not_applicable` | 公司研究区分一级和二级市场；行业研究填写 `not_applicable` |
| `listing_status` | `listed`、`unlisted`、`not_applicable` | 记录上市状态核验结果 |
| `listing_exchange` | 交易所官方名称或统一简称 | 上市公司必填，未上市公司和行业研究留空 |
| `ticker` | 官方证券代码 | 上市公司必填，未上市公司和行业研究留空 |
| `industry_orientation` | `consumer`、`technology`、`hybrid` | 决定行业与公司研究的分析框架 |
| `analysis_dimensions` | `consumer`、`technology`、`integration` | 消费或科技方向填写单一维度；融合方向固定填写三个维度 |
| `orientation_rationale` | 完整判断理由 | 说明产业链位置、客户、购买决策和利润来源 |
| `company_maturity` | `早期验证`、`增长期`、`成熟未上市`、`拟上市`、`上市运营`、`不适用` | 决定指标深度与尽调可得性 |
| `information_availability` | `稀疏`、`部分`、`充分` | 决定来源深度和判断边界 |
| `output_profile` | 下表九个固定值 | 由三级判断自动生成，不允许自由填写 |

## 第二级行业方向判断

消费方向以终端消费者或家庭为主要购买者，需求、品牌、品类、渠道、价格、复购和用户体验是主要利润变量。直接向消费者销售成品或服务，并依靠品牌和渠道完成交易，是消费方向的重要信号。

科技方向多位于产业链上游或中游，主要客户为企业、机构或政府。客户采购主要评估性能、成本、良率、可靠性、部署、认证和工程验证。企业直接销售材料、部件、设备、软件或技术服务，仍属于科技方向，因为交易对象和竞争机制并非终端消费。

消费科技融合方向同时满足两组条件。终端消费者的需求、品牌、渠道、价格和体验直接影响收入；技术路线、核心器件、工程能力、性能成本取舍和产品迭代也直接影响购买决策、毛利或竞争壁垒。消费电子、智能汽车和面向消费者的智能硬件可按此方向判断。

融合方向需要两套逻辑均对投资判断具有实质影响。技术仅用于后台运营、普通生产或营销支持时继续使用消费方向；产品具有消费场景，但主要客户仍是企业且采购由工程指标决定时继续使用科技方向。消费方向的 `analysis_dimensions` 固定为 `[consumer]`，科技方向固定为 `[technology]`，融合方向固定为 `[consumer, technology, integration]`。任务卡必须在 `orientation_rationale` 中分别记录消费驱动、科技驱动以及二者如何共同影响收入、利润和竞争。

## 九条固定输出路径

| `output_profile` | 触发条件 | 必须输出 |
| --- | --- | --- |
| `industry_consumer` | 仅给出行业，且行业侧重消费 | 行业定义与分类、用户与场景、需求与支付意愿、品类和产品结构、品牌、渠道、价格体系、供应链、市场规模、竞争、增长驱动、风险和投资方向 |
| `industry_technology` | 仅给出行业，且行业侧重科技 | 行业定义与分类、技术栈与主流路线、工程瓶颈、产业链位置、上下游、供需、市场规模、竞争、商业化进度、风险和投资方向 |
| `industry_hybrid` | 仅给出行业，且消费与科技共同决定竞争和盈利 | 同时覆盖用户与场景、需求、品类、品牌、渠道、价格、技术栈、核心器件、主流路线、工程瓶颈、供应链、市场规模、竞争和投资方向，并解释技术如何转化为消费者价值、定价能力、毛利和品牌差异 |
| `primary_consumer_company` | 给出未上市公司，且所属行业侧重消费 | 行业研究、投资要点、创始人与团队、估值、融资历程、主营业务和主要产品、用户、品牌、渠道、价格、复购、供应链、业务与产品评价、风险及三至六项尽调动作 |
| `primary_technology_company` | 给出未上市公司，且所属行业侧重科技 | 行业研究、投资要点、创始人与团队、估值、融资历程、主营业务和主要产品、技术路线、工程瓶颈、客户验证、生产或部署、成本与性能、业务与产品评价、风险及三至六项尽调动作 |
| `primary_hybrid_company` | 给出未上市公司，且所属行业为消费科技融合方向 | 一级市场共同内容、消费者需求、品牌、渠道、价格、复购、技术路线、核心器件、工程瓶颈、量产验证、供应链、技术向用户价值和毛利的转化、业务与产品评价、风险及三至六项尽调动作 |
| `secondary_consumer_company` | 给出全球任一交易所上市公司，且所属行业侧重消费 | 行业研究、上市主体与证券信息、投资要点、管理层与股权、品牌和产品结构、收入利润与现金流、渠道和终端销售、盈利能力、竞争、估值、催化剂、风险和跟踪指标 |
| `secondary_technology_company` | 给出全球任一交易所上市公司，且所属行业侧重科技 | 行业研究、上市主体与证券信息、投资要点、技术与产品路线、客户与订单、生产或部署、分部财务、研发与资本开支、竞争、估值、催化剂、风险和跟踪指标 |
| `secondary_hybrid_company` | 给出全球任一交易所上市公司，且所属行业为消费科技融合方向 | 二级市场共同内容、用户和产品结构、品牌、渠道、价格、终端销售、技术与产品路线、核心器件、研发与资本开支、供应链、毛利和现金流、技术商业化兑现、竞争、估值、催化剂、风险和跟踪指标 |

行业研究在第二级结束，不进入公司研究，也不因报告中列举代表性公司而触发第三级。具体公司研究必须先完成所属行业研究，再把篇幅重点转向公司。

## 信息来源路由

- `早期验证` 与 `稀疏`：官网、产品页、创始人访谈、融资公告、投资方信息、客户或渠道外部反馈。
- `增长期` 与 `部分`：增加融资文件、招聘与组织线索、渠道和客户验证、行业数据库。
- `成熟未上市` 或 `拟上市` 与 `充分`：增加审计财务、股权文件、监管辅导、客户集中度和正式尽调材料。
- `上市运营`：交易所文件、年报、公告、公司投资者关系材料和行业原始数据优先，媒体仅用于解释和线索。

公司自述与独立来源分开记录。来源等级表示权威性，`source_role` 表示来源角色，`independence` 表示是否独立验证。
