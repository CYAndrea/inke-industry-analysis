# 回归测试用例

每次对 Skill 作结构性修改后，至少走查以下三类请求，再运行 `scripts/validate_artifact_bundle.py` 与 Skill 校验器。所有样例只交付一个完整版本。

| 场景 | 请求示例 | 预期行为 |
| --- | --- | --- |
| 正常聊天 | “研究中国种业，标的是隆平高科，以聊天格式输出” | 自动识别上市公司，给出投资要点、证据链接、风险与待核验项 |
| 正常 Excel | “研究中国种业，标的是隆平高科，交付 Excel” | 自动识别上市公司，建立完整阶段产物并输出经过渲染检查的工作簿 |
| 边界 | “研究 Somnia Lab，一级投资，Excel 交付” | 以产品、融资、渠道与少量外部反馈建立研究，不要求上市公司式经营指标；竞品检索覆盖体验或渠道模式 |
| 不适用 | “元气森林上市了吗？” | 不启动完整研究流程，只核验并回答单一事实 |
| 无标的行业 | “研究中国宠物零食行业，Excel 交付” | 使用无标的结构，拆开总市场、细分市场与线上监测口径；输出供需、竞争簇和可关注方向 |
| 一级项目 | “研究一家 AI 陪伴硬件公司，Excel 交付” | 仅提出现实可得的项目核验动作；不要求月度留存、库存天数、区域利润和单厂成本 |
| 科技行业 | “帮我研究一下锂电池行业，以聊天格式输出” | 识别为无标的行业和科技方向，使用 `industry_technology`，在第二级结束路由，不触发公司研究 |
| 融合行业 | “帮我研究消费电子行业，以聊天格式输出” | 识别为无标的消费科技融合方向，使用 `industry_hybrid`，同时覆盖消费者、品牌、渠道、价格、技术栈、核心器件、工程瓶颈及技术商业转化 |
| 二级消费公司 | “帮我研究贵州茅台，以聊天格式输出” | 先核验全球上市状态、交易所与证券代码，再识别消费方向，使用 `secondary_consumer_company`，完成行业研究和公司重点研究 |
| 二级融合公司 | “研究一家全球上市的消费电子公司，Excel 交付” | 核验交易所和证券代码后使用 `secondary_hybrid_company`，结合消费和科技公司模板，并分析技术对产品价值、毛利和品牌差异的贡献 |
| 硬科技公司 | “研究新能源汽车行业，公司是比亚迪，Excel 交付” | 路由为二级市场科技公司，技术栈按层级写出路线、机制、约束、验证状态和投资影响；工程瓶颈不得只列关键词 |
| 一级消费公司 | “研究元气森林，Excel 交付” | 核验未上市状态后路由为一级市场消费公司，聚焦创始团队、估值、融资、品类、产品、品牌、渠道、业务和产品评价 |
| 触发边界 | “什么是毛利率？” | 不触发行研编排；直接回答概念问题 |
| 格式缺失 | “做一个光轮智能行业研究” | 只询问“本次希望以聊天格式还是 Excel 格式输出？”，收到选择前不开始正式研究 |
| Excel叙事 | “研究低碳经济，Excel交付” | 先形成叙事稿；正文页使用结论式标题和连续段落，隐藏洞察、驱动因素、建议等分析标签；宽表仅出现在数据或必要比较页 |
| 阶段门禁 | “研究一家 AI 陪伴硬件公司，Excel 交付” | 依次形成行业分析、公司分析、竞争地图和综合判断；综合判断通过前不创建叙事稿，叙事稿不得使用综合判断之外的新证据 |

## 机器验收断言

- 所有任务必须具备研究对象、行业方向、判断理由、公司成熟度、信息可得性和固定 `output_profile`。有标的任务还需记录全球上市状态；上市公司必须记录交易所和证券代码。
- `output_profile` 必须等于路由字段推导结果，禁止自定义组合名称。
- 行业任务必须在第二级结束，公司任务必须进入第三级并包含所属行业研究。
- 科技方向的工程瓶颈每项至少两句，并同时说明问题、原因或影响、当前状态和投资意义。
- 融合方向必须同时存在消费分析、科技分析和技术商业转化分析，缺少其中任一部分不得通过质量验收。
- 来源台账必须同时记录权威性、来源角色和独立性；来源计数必须与台账逐条一致。
- 交付阶段必须存在渲染检查结果；竞品阶段必须列出纳入、搜索后排除和停止理由。
- 交付前必须存在通过校验的 `narrative-draft.json`；正文不能依赖项目符号、标签卡片或宽表完成主要论证。
- Excel 路径必须存在 `industry-analysis.json` 与 `analysis-synthesis.json`；公司任务还必须存在 `company-analysis.json`，行业任务的公司分析路径必须为空。
- 叙事稿和研究记录中的结论证据必须是综合判断阶段已经纳入的证据，禁止写作阶段新增研究结论。
- Pre-IPO、IPO 辅导、交易所受理或招股阶段在正式挂牌前仍归一级市场，不得误判为二级市场。
- 研究记录不得复制来源台账；所有可见结论与图表使用证据编号回连唯一证据文件。
- 用户未指定格式时必须先询问并暂停；聊天路径不要求建立 Excel 阶段文件，Excel 路径必须生成并校验全部阶段产物。

测试记录应说明触发是否准确、是否提出了多余问题、是否选择正确来源路径、是否遵守一级投资边界与交付规范、是否生成全部阶段产物。
