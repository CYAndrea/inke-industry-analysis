# 证据与公司研究

## 证据台账字段

| 字段 | 要求 |
| --- | --- |
| 结论或数字 | 可独立理解，避免只写标签 |
| 事实类型 | 事实、预测、估算、推演或判断 |
| 来源 | 名称、标题、发布日期和完整直达链接 |
| 来源角色 | 原始披露、公司自述、投资方披露、独立媒体、行业数据库或渠道监测 |
| 独立性 | 独立验证、部分独立、公司自述或未知 |
| 口径 | 地区、期间、单位、分子分母或产品边界 |
| 使用方式 | 支持何种判断，是否存在外推 |
| 待核验事项 | 缺少什么信息会改变结论 |

市场或公司关键数字还需记录来源等级、地区、期间、单位、计算方式和冲突来源。市场总盘、细分市场、平台监测与公司收入必须分别建行，禁止在同一结论中无标记拼接。

## 来源路由

| 信息类型 | 优先来源 | 使用限制 |
| --- | --- | --- |
| 上市公司财务与业务数据 | 定期报告、公告、交易所材料 | 不用媒体转述替代精确数字 |
| 市场规模、份额与政策 | 行业协会、政府、正式研究报告、可复现数据库 | 明确历史、预测或模型测算 |
| 一级市场项目与竞争动态 | 高质量财经媒体、行业媒体、知名公众号、公司公开材料 | 记录发布时间与直达链接 |
| 产品与技术参数 | 官网、产品页、技术白皮书、开发者文档 | 营销说法与可验证性能分开 |
| 融资与股权 | 公司公告、投资方公告、可信交易媒体 | 未证实的估值不作为正式估值输入 |

## 公司研究卡

每个重点标的固定记录：准确法律主体、全球上市状态、交易所与证券代码、资本市场阶段、消费、科技或融合方向及判断理由、公司成熟度、信息完整度、产品、用户与付费方、商业模式、核心证据、主要可比项目、关键限制条件和下一步核验动作。融合方向分别记录消费驱动、科技驱动及二者对收入、利润和竞争的连接。

公司成熟度和信息完整度决定数据来源与指标颗粒度。早期验证项目优先使用官网、产品页、创始人访谈、融资媒体和少量客户或渠道反馈；成熟未上市项目增加审计财务、股权文件、客户集中度和正式尽调材料；上市运营公司以年报、公告、交易所材料和可复现行业数据为主。

## 一级投资核验

初步阶段只回答三至六个关键问题，材料与动作应现实可得：

- 管理层对近两年收入、盈利或现金趋势的概要说明。
- 主要增长品类、客户或渠道的形成机制。
- 最新融资时间、主要股东与下一轮融资意向。
- 两至三位客户、渠道伙伴、终端或行业人士的外部反馈。
- 产品可用性、定价、交付和复购的直接证据。

只有正式尽调、公司可提供或交易条款直接依赖时，才扩大至分品类收入、库存、回款、单厂成本、区域利润等颗粒度指标。

## 消费品经营术语

消费品研究中不要把“动销”当作默认表达。根据证据口径分别使用“终端销售表现”“实际销售进度”“渠道出货与终端消化”“门店销售反馈”等具体说法。只有来源明确使用“动销”时才保留原词，并补充其统计对象、时间范围和渠道范围，避免把出货、铺货、加权分销与消费者购买混为一谈。

来源等级采用 A 至 D：A 为原始披露，B 为指定高质量媒体与可信行业数据库，C 为行业报告转述或平台榜单，D 为营销软文与未经证实社媒。关键财务、政策、产品参数和精确数字优先使用 A 级；一级项目融资、竞争动态和市场解释可使用 B 级，但必须保留发布日期与直达链接。
