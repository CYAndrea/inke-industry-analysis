# Skill 评测量表

评测对象分为触发路由、研究过程、证据质量、内容质量和交付质量五个维度。每个维度按 0 至 2 分记录：0 分表示未满足，1 分表示部分满足，2 分表示稳定满足。

| 维度 | 评测重点 | 通过标准 |
| --- | --- | --- |
| 触发与边界 | 行业研究触发率、单一事实误触发率 | 研究请求触发率不低于 95%，单一事实误触发不超过 5% |
| 路由准确性 | 全球上市状态、一级或二级市场、行业或公司、消费、科技或融合方向、成熟度、信息可得性和输出配置 | 行业样例在第二级结束，公司样例完成三级判断；消费电子等融合样例结合两套模板；10 个样例中至少 9 个路由正确，且无自由组合 profile |
| 证据完整性 | 来源直链、来源等级、来源角色、独立性、口径和时间 | 关键数字 100% 有直达链接，关键判断至少有一条可追溯证据 |
| 内容质量 | 投资要点、技术栈、工程瓶颈、竞品覆盖、一级指标可得性 | 硬科技工程瓶颈无关键词串；一级项目无无法取得的精细经营指标 |
| 交付质量 | Excel 列宽与行高、长文本可读性、来源链接、渲染检查 | 无明显裁切、链接可点击、长文本区域无无意义边框、阶段产物齐备 |

## 评测方式

使用 `references/test-cases.md` 的场景集，分别记录模型输出、路由字段、阶段产物和校验器结果。每次修改至少执行一次正向样例、一次边界样例和一次反向样例。若关键硬门槛失败，即使平均分达标也判定为未通过。

## 关键硬门槛

1. 路由字段缺失或 `output_profile` 与推导结果不一致。
2. 关键数字无链接、来源计数与台账不一致，或阶段产物引用未知证据编号。
3. 技术型研究把工程瓶颈写成关键词罗列。
4. 一级项目要求内部通常不会统计的指标作为必交材料。
5. 交付文件存在明显裁切、缺失链接、未完成渲染检查或未通过跨产物对账。
