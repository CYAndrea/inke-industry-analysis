# inke-industry-analysis

团队行业研究 Skill 套件，面向中文行业研究、公司研究、竞品分析与投资判断。

## 目录

- `team-industry-research`：主编排 Skill
- `team-industry-research/subskills/team-research-intake`：任务卡与研究边界
- `team-industry-research/subskills/team-research-evidence`：证据台账、市场与技术研究
- `team-industry-research/subskills/team-research-competition`：竞品地图与竞争判断
- `team-industry-research/subskills/team-research-editorial`：咨询叙事稿
- `team-industry-research/subskills/team-research-delivery`：飞书、Word、Excel、PDF 交付
- `team-industry-research/subskills/team-research-quality`：证据、结构与版式验收

## 安装

在 Codex Skill 安装器中，将仓库设为 `CYAndrea/inke-industry-analysis`，路径设为 `team-industry-research`。主 Skill 安装后会同时获得 `subskills/` 下的六个阶段模块，无需重复安装。
